# Etsy Launch — Blog Post Content

The blog system renders article content as plain text with one link button, so the
interactive part of the announcement (step-by-step guide + highlighted buttons)
lives on the dedicated page **`/etsy-guide`** (already feature-flag gated).

Create the post in **Admin → ბლოგის მართვა** as an **Article** when you're ready
to launch (after flipping the master Etsy flag). Paste the fields below.

> The "link" field (article URL) should be: `/etsy-guide`
> Publishing the post is your launch switch for the announcement itself —
> keep it unpublished while testing.

## Checklist before publishing the post

1. Master Etsy flag ON (Admin → Etsy ინტეგრაცია → ინტეგრაციის მართვა).
2. `/etsy-guide` opens with the full guide (not the "coming soon" screen).
3. The `#etsy-button` deep link works: `/admin/products#etsy-button` scrolls to
   and pulses the orange button for a seller with approved products.
4. Cover image: pick a wide image (e.g. an artwork collage with the Etsy-orange
   accent) in the blog editor.
